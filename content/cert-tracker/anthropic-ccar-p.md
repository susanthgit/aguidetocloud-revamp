## Who Should Take This Exam?

The guide describes experienced solution architects, technical leads, and engineers who take responsibility for a Claude system from discovery through production. It recommends three or more years in systems architecture or platform engineering, and six or more months working with Claude or comparable systems in production. These are recommendations, not mandatory prerequisites. Partner-only registration still applies.

Architect - Foundations is not a mandatory prerequisite for Professional. They are separate credentials. This bank focuses on choosing and defending an architecture under concrete constraints, rather than recalling an API field or a product label in isolation.

## Study Tips

1. **Start with Integration**, the largest official domain at 19%. Trace data, permissions, retrieval, tool calls, and monitoring through an actual system. Explain why each connection belongs there.
2. **Make trade-offs measurable.** Define an acceptable output, latency target, and cost budget before comparing models or architectures. A larger model is not automatically the right choice.
3. **Separate architecture from implementation trivia.** Explain which steps need a fixed workflow, which need model judgement, and where a person must approve a consequential action.
4. **Use evaluations as acceptance criteria.** Include representative successful cases, difficult cases, and unsafe requests. Re-run the same tests when a model, prompt, retrieval strategy, or tool changes.
5. **Map each obligation to a control and an owner.** Choosing Claude does not, by itself, make the surrounding application compliant. Know what evidence a reviewer needs.
6. **Practise the handoff.** Document decisions, failure modes, escalation routes, and operating instructions so the team can support the system without its original architect.
