## Who Should Take This Exam?

The CIS-SIR is designed for **implementation specialists who configure and support ServiceNow Security Incident Response** — the people who set up security incident creation, wire in threat intelligence and integrations, tune calculator groups and severity, and build the playbooks and flows that drive a response. ServiceNow enforces the entry requirement below rather than recommending experience.

**Prerequisites:** Certified Implementation Specialist – Data Foundations (CMDB and CSDM) certification is required before registering

**Typical study time:** 6-10 weeks of focused study

## ServiceNow Certification Path

ServiceNow gates this credential, so the order matters. Start with the **Certified System Administrator (CSA)** for the platform itself — navigation and instance configuration, lists and forms, the data schema and access control, Service Catalog and Workflow Studio, the CMDB, and update sets. Then take **Certified Implementation Specialist – Data Foundations (CMDB and CSDM)**, which ServiceNow requires you to hold before it will let you register for CIS-SIR. The Security Incident Response specialisation comes last.
