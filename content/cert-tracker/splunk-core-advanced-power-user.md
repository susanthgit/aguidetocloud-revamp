## Splunk Certification Path

Start with the **Splunk Core Certified User** (basic searching and reporting), then earn the **Splunk Core Certified Power User** (SPL, knowledge objects, data models, and the CIM) — which is the required prerequisite for this exam. The **Splunk Core Certified Advanced Power User** (this exam) is the next step up, going deep on advanced SPL, acceleration and Simple XML dashboards. From there, advance to the **Splunk Enterprise Certified Admin** and specialty tracks including Architect and Cloud Administration, plus security-focused credentials built on Splunk Enterprise Security.
