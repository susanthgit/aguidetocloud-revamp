## Turn Each Answer Into Excel Practice

Start with a question. Read the explanation even if your answer was right. Then complete its **Try in Excel** task and compare your workbook with the stated expected result. The bank does not inspect your workbook: you must carry out and check the work yourself.

These four short exercises show the approach. Use a new practice workbook, not a work file containing personal or confidential information.

### Data: Keep an Identifier Intact

For a hypothetical exercise, enter the identifiers `00123` and `00456` as text. Save a copy as CSV, then import it using **Data > From Text/CSV** and ensure the identifier column is typed as text before loading.

**Check:** both identifiers still contain five characters, including the leading zeros. Explain why a number format alone cannot restore the original identifier length once it has been discarded during conversion.

### Process: Calculate a Late-Task Count

Create a small exercise table with three due dates: yesterday, today and tomorrow. Set each status to `Open`. Use `COUNTIFS` to count rows whose due date is strictly before today and whose status is `Open`.

**Check:** the result is **1**. Change yesterday's status to `Closed`; the count should become **0**. Explain why a due date of today is excluded by a strict "before today" rule.

### Resources: Work Backwards From a Target

Use exercise cells for units, price and revenue. Set price to **20**, units to **10**, and revenue to `units * price`. Use **Goal Seek** to make revenue **300** by changing units.

**Check:** units becomes **15**, while price remains **20**. Goal Seek changes one input to meet one formula result; it is not a tool for solving several capacity constraints at once.

### Reporting: Check the Filter Context

Build an exercise table with region and sales columns: North **10**, North **20**, South **40**. Create a PivotTable summing sales by region, then add a region slicer.

**Check:** the unfiltered total is **70**; selecting North shows **30**. Clear the slicer and confirm **70** returns. A filter changes the view; it does not prevent someone with workbook access from seeing the underlying data.

## A Practical Study Routine

1. **Find a gap:** use the free preview to identify a concept you cannot yet explain.
2. **Read the source:** follow the question's Microsoft reference and check platform applicability.
3. **Do the task:** complete the exercise in Excel, including its expected-result check.
4. **Change an input:** explain what should change before recalculating or refreshing.
5. **Practise without prompts:** repeat a small workflow from a plain-language requirement, not a memorised menu sequence.
