## Who is this exam for?

DP-420 is for developers building applications with Azure Cosmos DB, including application data, retrieval indexes, conversation state and agent memory.

Microsoft expects application development experience with C# or Python, familiarity with Azure services, and an understanding of generative AI and retrieval-based systems. You should be able to explain your data model, partitioning and security choices and test their effects on performance and cost.

## Skills Measured

### Design and develop database solutions (40-45%)

#### Evaluate resource models and SDK solutions

- Evaluate consistency levels and request-unit consumption.
- Choose and configure throughput.
- Configure account and container settings.
- Create and manage databases and containers.
- Initialize SDK clients and connections.

#### Implement database operations

- Write queries and parameterized queries with paging and continuation tokens.
- Use point reads where the id and partition key are known.
- Create, replace, update, patch and delete items.
- Choose bulk, batch and transactional operations.
- Configure container and item time to live.
- Handle concurrent changes deliberately.

#### Design data models and partitioning

- Model the data from actual access patterns and operational requirements.
- Choose partition keys using cardinality, access patterns and write distribution.
- Decide when to embed or reference related data.
- Evaluate how partition choices affect performance and growth.
- Implement hierarchical and synthetic keys and multitenant designs.
- Identify partitioning anti-patterns during solution reviews.
- Estimate workload costs.

#### Implement change feed

- Implement change-feed operations.
- Distinguish the processor model from pull mode.
- Configure lease containers.
- Choose latest-version or all-versions-and-deletes processing.
- Implement copy-container jobs and plan their cutover.

#### Use AI-assisted development tools

- Use Cosmos DB Agent Kit for recommended development approaches.
- Use Agent Kit to accelerate AI application development.
- Validate generated recommendations against the documentation and real workload.

### Secure, optimize, and deploy database solutions (30-35%)

#### Implement security controls

- Configure authentication and authorization.
- Configure network access.
- Configure dynamic data masking, including the caller's effective unmask privileges.

#### Implement availability and recovery

- Configure backup and restore.
- Configure multi-region reads and writes.
- Configure supported partition-failover solutions.

#### Diagnose and improve performance

- Optimize queries and analyze query and index metrics.
- Measure end-to-end application latency against service objectives.
- Configure Azure Monitor alerts.
- Analyze diagnostic logs with Log Analytics.

#### Manage fleets

- Configure fleet-level throughput management across accounts and subscriptions.
- Monitor fleets using fleet analytics.

### Implement AI and analytics capabilities in database solutions (20-25%)

#### Design AI retrieval

- Implement full-text search.
- Select vector data types, dimensions and indexes.
- Design vector partitioning and sharded DiskANN.
- Implement vector and hybrid search.
- Optimize full-text and vector performance.
- Build retrieval-augmented generation with relevant grounding data.

#### Design agent memory stores

- Store durable agent memory.
- Implement ordered conversation state.
- Implement semantic memory with suitable scope and retention.

#### Implement operational analytics

- Choose between Azure Cosmos DB and native Cosmos DB in Microsoft Fabric.
- Configure and monitor mirroring into Fabric.
- Query mirrored JSON using T-SQL and Spark.
- Read and write operational Cosmos DB data from Fabric with the Spark connector.

Dedicated groups for server-side JavaScript, general cross-service integration, general data movement and DevOps were removed from the current guide. Those technologies can remain useful, but they are not a substitute for the new retrieval, memory and fleet objectives.
