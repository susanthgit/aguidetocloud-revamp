## About the 1Z0-1177-26 Exam

> Master the Oracle Governed Analytics Professional with Oracle Analytics Cloud exam (1Z0-1177-26) — building and refining analyses, views and calculations, formatting with filters, selection steps, prompts and variables, dashboard design with Dashboard Builder, prompts, pages and briefing books, data connectivity and artifact migration, administration, delivery and security, plus the full Oracle Analytics Publisher stack: data models, Layout Editor and RTF Template Builder, Excel and eText templates, scheduling, bursting and delivery, data sources, translations and secure reporting.

The Governed Analytics Professional with Oracle Analytics Cloud certification validates that you can build governed, shareable analytics content in Oracle Analytics Cloud — and then deliver it as pixel-perfect, scheduled, secured reporting through Oracle Analytics Publisher. It is the rare Oracle analytics credential that scores both halves of that story, with roughly 55% on the Oracle Analytics Cloud side and 45% on the Publisher side.

## Who Should Take This Exam?

This exam is aimed at **business analysts, BI analysts, reporting analysts, BI developers and data analysts** who already work in Oracle Analytics Cloud day to day — the people who build the analyses, design the dashboards, and own the scheduled reports that the rest of the business reads.

It rewards product knowledge over infrastructure administration. The questions turn on how Oracle Analytics behaves and which object is the right one to reach for — which view type, which filter mechanism, which template technology, which delivery channel — rather than on provisioning or platform operations.

**Prerequisites:** None (hands-on experience with Oracle Analytics Cloud and Oracle Analytics Publisher recommended)

**Typical study time:** 8-12 weeks alongside regular hands-on use

## Exam Domains & Weights

The 1Z0-1177-26 exam covers **10 domains**, and Oracle publishes an explicit weight for each one. Focus your study time based on the weights below — higher-weighted domains have more exam questions.

| Domain | Weight | Practice Qs |
|--------|--------|-------------|
| Understanding Oracle Analytics Cloud | 5% | 22 |
| Managing and Creating Analyses, Views, and Content in Oracle Analytics | 10% | 25 |
| Formatting Data and Managing Filters, Selection Steps, and Variables in Oracle Analytics | 10% | 25 |
| Designing, Creating, and Enhancing Dashboards in Oracle Analytics | 10% | 25 |
| Connecting to Data Sources and Migrating Artifacts to Oracle Analytics Cloud | 10% | 25 |
| Managing Administration, Security, and Performance in Oracle Analytics Cloud | 10% | 25 |
| Exploring and Creating Reports and Data Models in Oracle Analytics Publisher | 5% | 22 |
| Building and Formatting Reports Using Layout Editor and Template Builder | 15% | 28 |
| Managing Report Scheduling, Data Sources, Administration, and Translations in Oracle Analytics Publisher | 15% | 28 |
| Managing and Securing Oracle Analytics Publisher in Oracle Analytics Cloud | 10% | 25 |
| **Total** | **100%** | **250** |

> 💡 **Study tip:** Two domains tie for the heaviest weight at 15% — **Building and Formatting Reports Using Layout Editor and Template Builder** and **Managing Report Scheduling, Data Sources, Administration, and Translations**. Both are Oracle Analytics Publisher topics, so start there: together they are 30% of the exam, and the Publisher domains as a group carry 45%. The two 5% domains (**Understanding Oracle Analytics Cloud** and **Exploring and Creating Reports and Data Models in Oracle Analytics Publisher**) are the lightest, but they set up vocabulary the heavier domains assume.
