## About the AB-410 Exam

> Build intelligent business applications on Microsoft Power Platform — where Dataverse, apps, automation and AI meet.

Microsoft Certified: Intelligent Applications Builder Associate is the successor to PL-200. It covers the foundation you build on (Dataverse tables, columns, relationships, security, prompt columns and row summaries), the applications you build (model-driven apps, canvas apps, generative pages, and canvas apps that become Copilot Studio agents), and the logic that makes them work (cloud flows, business rules, business process flows, and AI Hub prompts and models).

It sits in Microsoft's Application development and Artificial intelligence subject areas, and spans Power Apps, Power Automate, Power BI, Power Pages and Power Platform.

## Who Should Take This Exam?

AB-410 is aimed at **makers and developers who build business applications** on Power Platform — the people who model the data, build the app, and wire up the automation behind it.

You'll be comfortable if you can already model data in Dataverse, choose the right column type without looking it up, build both model-driven and canvas apps, and automate with cloud flows and business rules. Familiarity with Power Fx helps throughout.

**Typical study time:** 4-8 weeks of focused study (longer if Dataverse is new to you).

## Exam Domains & Weights

The AB-410 exam covers **3 domains** per Microsoft's published skills outline. Microsoft publishes these as ranges, not fixed percentages.

| Domain | Weight | Practice Qs |
|--------|--------|-------------|
| Create a foundation for intelligent applications | 25–30% | 70 |
| Create intelligent applications | 25–30% | 70 |
| Build business application logic and automation | 40–45% | 110 |
| **Total** | **100%** | **250** |

> 💡 **Study tip:** **Build business application logic and automation** is nearly half the exam at 40–45%. Start there. The questions that separate passes from fails are usually column types (calculated vs rollup vs formula) and business process flow behaviour — not the AI features people expect to be hard.

### Domain 1 — Create a foundation for intelligent applications (25–30%)

- **Design Power Platform solutions by using AI-enabled tools** — analyse requirements to identify components and implementation options, evaluate built-in agents to include in the solution, recommend extensibility options, recommend environment types, and apply a Power Platform solution and ALM strategy
- **Build data models** — create and edit tables in the data workspace, create and modify standard tables, configure table properties, create and modify columns, configure table relationships, configure prompt columns, configure row summaries, configure public views, configure main forms, and configure security

### Domain 2 — Create intelligent applications (25–30%)

- **Create model-driven apps** — create and configure forms and views, create generative pages by using natural language, compose a model-driven app, configure access to forms and views, configure access to apps, and create charts and dashboards
- **Create canvas apps** — create a canvas app using data, design for accessibility, performance, responsiveness and usability, automate business processes from canvas apps, create reusable components (named formulas, user-defined functions, component libraries), manage variables and collections, implement error handling, test canvas apps including using Monitor, and create a Copilot Studio agent from a canvas app

### Domain 3 — Build business application logic and automation (40–45%)

- **Create cloud flows** — recommend triggers, evaluate and recommend connectors, manage approvals, configure actions, implement flow control with conditions and loops, and test and troubleshoot flows
- **Create prompts and models in AI Hub** — build prompts from templates or from blank, consume a prompt in apps and in cloud flows, add knowledge to a prompt, customise prompt settings including models, add inputs to a prompt, and consume an AI model in apps and in cloud flows
- **Implement business and process logic** — configure business rules, configure business process flows, configure calculated, rollup and formula columns, and evaluate use cases for business logic

> Reference: [Official AB-410 study guide on Microsoft Learn](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/ab-410).

## Study Tips

- **Start with Domain 3.** At 40–45% it's nearly half the exam, and it's the most hands-on.
- **Learn the column types properly.** Calculated, rollup and formula columns look interchangeable in a table designer and behave completely differently. This is the single richest source of exam questions in Domain 3.
- **Know the difference between a prompt column and a prompt in AI hub.** Both involve prompts. They're different objects, used in different places, and the exam will test that you know which is which.
- **Build something end to end.** A few related Dataverse tables, a model-driven app, a canvas app over the same data, and a flow that reacts to a change. That one project covers most of the outline.
- **Don't skip business process flows.** They're old Power Platform material that people assume is out of scope on an AI-flavoured exam. They aren't.
