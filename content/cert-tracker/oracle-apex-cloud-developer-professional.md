## About the ORACLE-APEX-CLOUD-DEVELOPER-PROFESSIONAL Exam

> Master the Oracle APEX Cloud Developer Professional exam (1Z0-771) - workspace and SQL Workshop setup, Page Designer, interactive reports and grids, faceted search, forms and master-detail pages, dynamic actions and application logic, REST Data Sources and Data Synchronization, Universal Theme and Template Components, authentication and authorization schemes, session state protection, Working Copy and one-click remote deployment, plus APEX Workflow, the APEX Assistant generative-AI features, and Progressive Web Apps.

The complete practice exam for the Oracle APEX Cloud Developer Professional certification (exam 1Z0-771, validated against Oracle APEX 24.2). A professional-level certification for low-code application developers, Oracle Database developers, and platform teams who design, build, secure, and deploy Oracle APEX applications on Autonomous Database and Oracle Cloud Infrastructure. Covers APEX Foundations, Workspace and SQL Workshop (APEX architecture and the ORDS request flow, provisioning and administering workspaces, Quick SQL, Object Browser, SQL Commands and Scripts, and loading data with Data Workshop); Pages, Regions, Reports and Forms (Page Designer, interactive reports and interactive grids, classic reports, faceted search and smart filters, cards regions, forms, and master-detail pages); Page Controls, Application Logic, Navigation and Dynamic Actions (page items and item types, computations, validations, processes and branches, dynamic actions and their true/false actions, lists of values, navigation menus and breadcrumbs, and shared components); Application Data, Themes and Extending Capabilities (APEX collections, REST Data Sources and REST-enabled SQL, Data Synchronization, Universal Theme, Theme Roller and theme styles, Template Components and live template options, plug-ins, automations, and charts, calendars, trees and maps); Application Security and the Deployment Lifecycle (authentication and authorization schemes, access control, session state protection and URL tampering, build options, supporting objects, application export and import, Working Copy, and one-click remote deployment); and Workflows, Generative AI and Progressive Web Apps (APEX Workflow and the Unified Task List, human tasks and approvals, the APEX Assistant and generative-AI service configuration, and installable Progressive Web Apps with push notifications).
