## About the GH-600 Exam

> Master agentic AI on GitHub — agent architecture and SDLC integration, tool use and MCP servers, memory and state, evaluation and tuning, multi-agent orchestration, and guardrails.

The complete practice exam for GitHub Certified: Agentic AI Developer (GH-600, 'Developing in Agentic AI Systems'). Covers preparing agent architecture and SDLC processes, separating planning from execution and validating agent plans, selecting and permissioning agent tools, configuring MCP servers including the GitHub remote MCP server, registries and allow lists, scoping agents to repositories and branches and invoking them from CI, short-term, long-term and external memory with Copilot Memory, context drift and durable artifacts, success criteria, automated scanning and root-cause analysis, multi-agent orchestration, isolation, conflict resolution and recovery, and autonomy levels, least-privilege scoping and human-in-the-loop guardrails — every question a real-world scenario with full explanations.
