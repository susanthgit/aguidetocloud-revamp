## About the OCI Application Integration Professional Exam

> Master the Oracle Cloud Infrastructure Application Integration Professional exam (1Z0-1042-26) - Oracle Integration Cloud connections and adapters, the connectivity agent, orchestrated and scheduled integrations, the data mapper, lookups, file handling, fault handling, monitoring, and the new AI and agentic capabilities.

The complete practice exam for the Oracle Cloud Infrastructure Application Integration Professional certification (exam 1Z0-1042-26, validated against Oracle Integration 3 on Oracle Cloud Infrastructure 2026). A professional-level certification for integration developers, application developers, solution architects, and platform engineers who design, build, secure, and operate integrations on Oracle Integration Cloud. Covers Getting Started with OIC Integrations (key components, core integration concepts, how integrations execute, and web services fundamentals across WSDL, SOAP, REST and JSON), Using OIC Connections and Adapters (configuring connections, the distinction between trigger and invoke roles, and deploying the on-premises connectivity agent), Creating Orchestrated Integrations (lookups, the data mapper, custom JavaScript libraries, orchestration flow actions, file handling options including stage file and the OIC File Server, and the global and scope-level fault handling framework), Creating Scheduled Integrations (defining schedules, converting scheduled integrations to app-driven, and using schedule parameters), Testing, Monitoring, and Troubleshooting Integrations (activation and deactivation, testing REST trigger-based integrations, import and export, and monitoring and troubleshooting integration instances), and Leveraging AI Features and Capabilities (AI capabilities in Oracle Integration, OCI AI service actions, generative AI and retrieval-augmented generation, and the AI assistant and agentic features) - every question uses a realistic integration scenario with full explanations, hints, exam tips, and per-option rationales.

## Who Should Take This Exam?

The certification is aimed at **integration developers, application developers, solution architects, and platform engineers** who design, build, secure, and operate integrations on Oracle Integration Cloud. It suits people who already build integration flows day to day and want their Oracle Integration 3 knowledge validated end to end — from configuring adapters and the connectivity agent, through orchestration, mapping and fault handling, to activation, monitoring and the newer AI and agentic capabilities.

**Prerequisites:** None required (Oracle recommends hands-on experience building and operating integrations in Oracle Integration Cloud)

**Typical study time:** 8-12 weeks of intensive study
