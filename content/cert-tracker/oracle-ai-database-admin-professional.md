## About the ORACLE-AI-DATABASE-ADMIN-PROFESSIONAL Exam

> Master the Oracle AI Database Administration Professional exam (1Z0-183) - multitenant CDB and PDB administration, RMAN backup and recovery, flashback, performance tuning with AWR, ASH and ADDM, Grid Infrastructure installation, patching and upgrades, and the new Oracle AI Database 26ai features including AI Vector Search, True Cache, Lock-Free Reservations and blockchain tables.

The complete practice exam for the Oracle AI Database Administration Professional certification (exam 1Z0-183, validated against Oracle AI Database 26ai). A professional-level certification for working database administrators, infrastructure engineers, and platform teams who install, operate, tune, protect, and upgrade a self-managed Oracle database estate on-premises, in the cloud, or hybrid. Covers Managing Multitenant Architecture (creating CDBs with DBCA, creating regular and application PDBs, cloning, relocating, unplugging and plugging, refreshable clones and the snapshot carousel, common versus local users, lockdown profiles, securing multitenant databases, and upgrading and transporting PDBs); Performing Backup and Recovery (configuring and using RMAN, backup sets versus image copies, full versus level 0 and differential versus cumulative incremental strategies, the fast recovery area and the recovery catalog, diagnosing failures with the Data Recovery Advisor, complete and point-in-time recovery, the flashback technologies, cross-platform transport, database duplication, and tuning and troubleshooting RMAN); Managing and Tuning Performance (basic tuning and diagnostics, metrics, alerts and baselines, AWR, ASH and ADDM, application monitoring, SQL statement processing and optimization, reducing the cost of SQL operations, Real Application Testing with SQL Performance Analyzer and Database Replay, instance tuning, and the In-Memory Column Store); Deploying, Patching and Upgrades (installing Grid Infrastructure and Oracle Database, creating databases with DBCA, applying patches with OPatch and datapatch, configuring Oracle Restart, and upgrading Grid Infrastructure and the database with AutoUpgrade); and New Features in Oracle AI Database (AI Vector Search with HNSW and IVF vector indexes, OLTP and core database enhancements, availability features such as True Cache, manageability and performance improvements, and database security enhancements).
