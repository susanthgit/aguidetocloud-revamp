## Who is this exam for?

AB-400 is for developers who extend Microsoft Power Platform with code, custom interfaces, automation and AI. You should be able to choose where logic belongs, implement it, secure it and troubleshoot the result.

Microsoft expects experience with Power Platform services, developer tools, JavaScript, TypeScript, JSON, Power Fx, C#, Python, HTML, YAML, REST APIs and Azure. The current guide also includes Microsoft Foundry and Copilot Studio.

## Skills Measured

### Build Microsoft Power Platform solutions (15-20%)

- Choose solution components, authentication and authorization.
- Decide between built-in features, client scripting, plug-ins, cloud services and automation.
- Select standard, virtual or elastic tables and connectors.
- Account for data policies, security roles, teams, business units and row sharing.
- Choose deterministic logic or generative approaches for the requirement.
- Design code apps, PCF components, generative pages, web resources and MCP app widgets.
- Design connectors, MCP servers, agents, integrations and monitoring.
- Manage solution dependencies, layers and environment variables.
- Implement Power Platform Pipelines and CI/CD with Power Platform Build Tools.

### Extend the user experience (25-30%)

- Use the model-driven app Client API, event handlers and Dataverse Web API.
- Configure commands, navigation, dialogs and notifications.
- Build PCF components with the correct lifecycle, manifest and interfaces.
- Package and deploy components, including Device, Utility and Web API features.
- Connect Power Apps code apps to Dataverse, connectors, flows and Copilot Studio agents.
- Perform table, metadata, action and function operations.
- Configure code app environment variables and Content Security Policy.
- Deploy, share, monitor and troubleshoot code apps.
- Use Application Insights, Monitor and browser tools to investigate performance.

### Extend Microsoft Power Platform (35-40%)

- Develop plug-ins using pipeline stages, execution context, images and the Organization service.
- Register plug-in components and implement custom APIs and business events.
- Configure Power Platform managed identity for plug-ins.
- Use Dataverse Web API and SDKs for .NET and Python.
- Handle API limits, OAuth, concurrency, transactions, bulk operations and background work.
- Use Azure Functions for long-running, scheduled and event-driven work.
- Authenticate Azure workloads to Power Platform using managed identities.
- Build cloud flow expressions, error handling, trigger filters, retries and child flows.
- Use service principals with the Dataverse connector.
- Connect coded Foundry agents to Power Platform MCP servers, Copilot Studio agents and Dataverse through Work IQ.

### Develop integrations (10-15%)

- Publish Dataverse events with the Plug-in Registration Tool and `IServiceEndpointNotificationService`.
- Choose service endpoints and listeners, including webhooks, Service Bus and Event Hubs.
- Synchronize Dataverse data using change tracking, alternate keys and `UpsertRequest`.
- Build custom connectors with authentication, policy templates and OpenAPI definitions.
- Expose Azure Functions through connectors and transform connector data with code.

## How to Prepare

Start with the official objectives and mark what you can demonstrate, not just recognize. Build a small solution that combines a model-driven app, a plug-in, a code app, a flow and an external integration.

Trace one request through its authentication, client code, Dataverse operation and downstream processing. Then change a security role, introduce an API limit and inspect the resulting errors. This makes the boundaries between the components easier to remember.

Give the most practice time to extending the platform and the user experience. They make up the largest published weight ranges. Keep checking the official guide as product features and exam objectives change.
