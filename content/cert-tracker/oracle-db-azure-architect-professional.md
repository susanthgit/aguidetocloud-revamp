## About the ORACLE-DB-AZURE-ARCHITECT-PROFESSIONAL Exam

> Master the Oracle AI Database@Azure Architect Professional exam (1Z0-1147) — the multicloud model behind Oracle Database@Azure and how Oracle-managed infrastructure sits inside an Azure region; purchasing through Azure Marketplace, onboarding a subscription and linking an OCI tenancy; identity federation between Microsoft Entra ID and OCI IAM; delegated subnets, network attachments, NSGs, user-defined routes and the default versus advanced networking feature sets; provisioning and operating Exadata Database Service on Dedicated Infrastructure and Autonomous Database Serverless; migrating with Zero Downtime Migration, Data Pump, RMAN and Data Guard; high availability and disaster recovery across availability zones and regions; and securing the service with TDE, customer-managed keys, Azure Monitor and OCI audit.

The complete practice exam for the Oracle AI Database@Azure Architect Professional certification (exam 1Z0-1147). Covers Introduction to Multicloud (why organisations run distributed and multicloud estates, where Oracle Database@Azure fits alongside Oracle Interconnect for Azure, and the shared-responsibility split between Microsoft, Oracle and the customer), Oracle AI Database@Azure Architecture and Onboarding (how Oracle-managed hardware is physically located inside Azure datacentres and presented as native Azure resources, the private offer and Azure Marketplace purchase flow, subscription and resource-provider onboarding, linking an Azure subscription to an OCI tenancy, mapping Azure regions and availability zones onto OCI availability zones, federating Microsoft Entra ID with OCI IAM for single sign-on, and the roles and permissions an architect must grant on both sides), Configure Oracle AI Database@Azure Networking (planning the delegated subnet and its sizing, Oracle.Database network attachments, the default and advanced networking feature sets and exactly which capabilities each one supports, network security groups, user-defined routes and route specificity, VNet peering and its unsupported combinations, ExpressRoute and site-to-site connectivity, DNS resolution and private endpoints, and the provider-feature registration a subscription needs before advanced networking works), Provision and operate Oracle AI Database@Azure Resources (creating and scaling Exadata Infrastructure and VM Clusters, provisioning container and pluggable databases, Autonomous Database Serverless workload types and elastic scaling, cloning and refreshing, patching and maintenance windows, quotas and limits, and monitoring with Azure Monitor, OCI metrics and the database management tooling), Migrate Oracle Databases to Oracle AI Database@Azure (choosing between physical and logical migration, Zero Downtime Migration in its online and offline modes, Data Pump export and import, RMAN backup-based migration, Data Guard and GoldenGate for near-zero-downtime cutover, cross-endian and version considerations, and validating and falling back safely), HA and DR with Oracle AI Database@Azure (Exadata redundancy and availability-zone placement, Data Guard and Autonomous Data Guard for local and cross-region standbys, automatic and manual backups to OCI Object Storage, restore and point-in-time recovery, RTO and RPO trade-offs, and switchover and failover procedures), and Secure Oracle AI Database@Azure (Transparent Data Encryption, Oracle-managed versus customer-managed keys and the vault that holds them, encryption in transit, database and infrastructure access control, separation of duties across the Azure and OCI control planes, auditing and logging on both platforms, and network isolation as a security boundary) — every question a real architectural decision a working multicloud architect has to make, with full explanations grounded in the official Microsoft Learn and Oracle documentation.
