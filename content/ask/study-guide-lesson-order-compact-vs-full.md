## The question

Hello Sush,

ive notice that the order in which the topics appear differs between compact and full mode. Its seems to be right in the full view and sorted differently in the compact mode. For example, MD-102 starts with "Auto Enrollment", whilst the full view has Device identity as starting point. This behavior was the same using Edge and also occured in other guides (For Example AB-900 starts with Authentication, whilst the full view has the "Welcome to MS 365" lesson as first)

Additonal note: Ive would just use full mode, but it only shows that topics are" free" and doesnt apply the checkmark on the left sidebar when I click the "Mark lesson as done" button. Latter also doesnt work only sometimes.

The actual contens of the guides are pure gold and having this sorted out (haha) would make them near perfect!

## The answer

Hi Jens — thank you, this is a genuinely helpful report, and you were right on both counts. 🙏

**The ordering.** The compact view and the full view really were disagreeing. The full view showed lessons in the intended teaching order, but the compact view was quietly falling back to alphabetical order — which is why MD-102 opened on "Auto-Enrollment" instead of "Device identity." The other guides you mentioned had the same cause. Both views now follow the same curriculum order, so they line up.

Chasing that down actually led somewhere I wasn't expecting: on **MS-102**, the same underlying issue was silently hiding an entire domain — all of Domain 3 (Manage Security and Threats with Microsoft Defender XDR), plus one Purview lesson, were missing from the study guide. That's fixed now too, so MS-102 shows the full 28 lessons across all four domains. So genuinely — thank you, your message surfaced more than the sort order.

**The checkmark.** Also a real gap on my end. "Mark lesson as done" was saving your progress, but the left sidebar was never wired to show it, so nothing changed visually. The sidebar now puts a green check next to each lesson you've completed — it updates the moment you mark one done, and stays in sync as you move between lessons.

Both are live now; a hard refresh (Ctrl+F5) should bring them through.

And thank you for the kind words about the guides — that honestly means a lot. Reports like this are the best way they get better, so if you spot anything else, please send it my way. 🙂

— Sush
