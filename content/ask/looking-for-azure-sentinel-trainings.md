## The question

Hi Is there any batch or one 2 one training option for Azure Sentinel from zero to Admin level ?

## The answer

Hi Shubham — thanks for asking! I don't run paid batch or 1:1 training — A Guide to Cloud is an education-first project rather than a training business — but for **zero-to-admin Microsoft Sentinel**, here's the path I'd take, all free:

- **[Microsoft Sentinel for Beginners — Full Hands-On Security Masterclass](https://www.aguidetocloud.com/cloud-labs/microsoft-sentinel-for-beginners-full-hands-on-security-masterclass/)** — a complete hands-on ramp, exactly the "from zero" walkthrough you're after.
- **[SC-200 Study Guide](https://www.aguidetocloud.com/cert-tracker/sc-200/)** — SC-200 is the certification that formally covers Sentinel; this is the structured route to admin-level.
- **[MS Learn — Configure SIEM security operations using Microsoft Sentinel](https://learn.microsoft.com/training/paths/configure-security-information-event-management/)** — Microsoft's own free learning path.

Work the masterclass first for the hands-on feel, then use SC-200 to formalise it. If there's a specific Sentinel topic you'd like a deeper walkthrough on, tell me and I'll look at building one. 🙂
