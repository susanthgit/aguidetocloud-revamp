## The question

The Security Copilot licensing discussion needs to include information about how it is made available to orgs with M365 E5

## The answer

Hey Dean — thanks for flagging this, great spot.

I've just updated the page with a [proper M365 E5 section](https://www.aguidetocloud.com/licensing/security-copilot/) (give Cloudflare ~2 min to deploy).

**Quick answer for the page-update record:**

Security Copilot is **NOT bundled with M365 E5** — it's a standalone pay-per-use product at $4 per Security Compute Unit (SCU) per hour.

That said, E5 customers are the natural buyer. Security Copilot's superpower is reasoning across signals it doesn't generate itself — and E5 is what provides those signals:

| E5 component | What Security Copilot uses it for |
|---|---|
| Defender XDR (endpoint, email, identity, cloud apps) | Cross-workload incident investigation |
| Entra ID P2 | User risk + conditional access context |
| Purview | Insider risk + DLP correlation |
| Intune | Device compliance signals |

Microsoft Sentinel is the one most people get caught by — Sentinel is **NOT in E5**, it's billed separately by GB ingested. You can still use Security Copilot without Sentinel, but cross-source threat hunting gets much weaker.

**Microsoft Learn references (added to the page):**
- [Security Copilot overview](https://learn.microsoft.com/en-us/copilot/security/microsoft-security-copilot)
- [Getting started](https://learn.microsoft.com/en-us/copilot/security/get-started-security-copilot)
- [Manage SCU usage](https://learn.microsoft.com/en-us/copilot/security/manage-usage)

Microsoft's [Security Copilot inclusion documentation](https://learn.microsoft.com/en-us/copilot/security/security-copilot-inclusion) explains availability for eligible Microsoft 365 E5 and E7 customers, including the phased rollout and included capacity. It should not be described as something every E5 customer must always purchase separately.
