## What Microsoft currently lists

Microsoft's public plan pages describe three offers:

| Offer | Microsoft's public description | Public price information |
|---|---|---|
| Office 365 A1 | Donated at no cost to eligible institutions; online-only apps and services. | Microsoft says no cost for eligible institutions. |
| Microsoft 365 Education A3 | Builds on foundational access with desktop apps, device management, and security. | Microsoft directs buyers to talk with an expert; no dollar amount is listed on the page. |
| Microsoft 365 Education A5 | Advanced security, analytics, and governance for complex institutions. | Microsoft directs buyers to talk with an expert; no dollar amount is listed on the page. |

Microsoft's current public Education plan page and comparison are the source of truth for these descriptions. They do not show a full A7 faculty feature comparison or a public A7 price. Education pricing can depend on the institution, program, region, and agreement, so this guide does not repeat unofficial estimates.

## Student Use Benefit: read the product names, not just the tier

The Student Use Benefit is a set of specific student-use product entitlements attached to qualifying products and academic programs. It does **not** mean that students automatically receive the same complete license as faculty.

| Qualifying faculty/staff product | Student Use Benefit products listed by Microsoft | Program availability | Student instances |
|---|---|---|---:|
| Microsoft 365 Education A3 | Office 365 A3 Student Use Benefit; Enterprise Mobility + Security A3 Student Use Benefit; Windows Education A3 Student Use Benefit; Minecraft: Education Edition | EES, CSP | 40 |
| Microsoft 365 Education A5 | Office 365 A5 Student Use Benefit; Enterprise Mobility + Security A5 Student Use Benefit; Windows Education A3 Student Use Benefit; Minecraft: Education Edition | EES, CSP | 40 |
| Microsoft 365 Education A7 | Office 365 A5 Student Use Benefit; Enterprise Mobility + Security A5 Student Use Benefit; Windows Education A3 Student Use Benefit; Minecraft: Education Edition | EES, CSP | 40 |

Microsoft's Product Terms table states the student-instance count per paid Faculty/Staff, Education Qualified User, or Knowledge Worker license. Confirm that the institution's agreement and program qualify before assigning these benefits.

## What A7 does—and does not—mean here

Microsoft Product Terms names Microsoft 365 Education A7 as a qualifying product for the Student Use Benefit. The student entitlement is the specific set in the table above. It is **not** a statement that students receive a full A7 faculty license, and it does not establish the faculty A7 feature set or its price. The public Education comparison page currently describes A1, A3, and A5; use Microsoft or the institution's licensing provider for A7 faculty plan details.

## Copilot and other add-ons

The A7 Student Use Benefit table does not list Microsoft 365 Copilot. Do not assume that Copilot or another add-on is included in a student entitlement from this table; check the current Microsoft product terms and the institution's agreement for the exact offer.

## Frequently Asked Questions

**1. Does A7 Student Use Benefit give students full A7?**

No. Microsoft Product Terms lists specific Student Use Benefit products for A7: Office 365 A5, Enterprise Mobility + Security A5, Windows Education A3, and Minecraft: Education Edition.

**2. Does A7 Student Use Benefit include the same Defender suite as the faculty plan?**

The public Product Terms table lists Office 365 A5 and Enterprise Mobility + Security A5 Student Use Benefits for A7, but does not itemize Defender components or promise the same suite as faculty. Check the institution's agreement for the exact student-use rights.

**3. How many student-use instances are listed for A7?**

The Product Terms table lists 40 per paid Faculty/Staff, Education Qualified User, or Knowledge Worker license, with availability through EES and CSP. Check the institution's agreement for eligibility.

**4. What price should I budget for A3, A5, or A7?**

The public Microsoft Education page says to talk with an expert about plan pricing and does not display dollar amounts for these plans. Get a current quote from Microsoft or the institution's education licensing provider.

**5. Does the Student Use Benefit include Copilot?**

Copilot is not listed in the A7 Student Use Benefit entitlements table. Confirm any separate Copilot offer against current Microsoft terms and the institution's agreement.
